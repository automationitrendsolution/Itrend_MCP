Connect in 3 steps
  1. Get a token. {% if can_connect %} Generate a token for {{ server.name }} and copy it. It is shown only once. {% else %} Ask an administrator for Connect access, then generate a token on this page. {% endif %}
  2. Use this address. 
    {{ server.connection_url }}
  3. Add it to your MCP client. For example, in Claude Code: 
    claude mcp add --transport http {{ server.slug }} {{ server.connection_url }} --header "Authorization: Bearer YOUR_TOKEN"
    Or in a JSON config for clients that connect over HTTP themselves (VS Code and others):
    {
  "{{ server.slug }}": {
    "type": "http",
    "url": "{{ server.connection_url }}",
    "headers": { "Authorization": "Bearer YOUR_TOKEN" }
  }
}
    Claude Desktop only starts local programs, so it connects through the small mcp-remote helper (needs Node.js). In Claude Desktop open Settings → Developer → Edit Config, add this inside "mcpServers", then quit Claude Desktop completely and reopen it:
    "{{ server.slug }}": {
  "command": "npx",
  "args": ["-y", "mcp-remote", "{{ server.connection_url }}",
           "--header", "Authorization:${AUTH_HEADER}"],
  "env": { "AUTH_HEADER": "Bearer YOUR_TOKEN" }
}
    The token is passed through env because on Windows npx can split arguments that contain a space.
Keep your token secret. If it leaks, revoke it under Access Tokens and make a new one.
